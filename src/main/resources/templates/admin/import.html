Expected columns

Header row (exact names): sku, category, subCategory, brand, name, subtitle, price, mrp, rating, ratingCount, stock, seller, image, gallery, description, highlights, specs, featured

  • category – slug such as mobiles-tablets, computers-accessories, fashion, home-living, beauty-personal-care, sports-fitness, books, toys-games, groceries
  • seller – the seller's username (must be an approved seller account)
  • image – a path such as /img/products/my-item.jpg (file placed in static/img/products) or an /uploads/… path
  • specs – |RAM:8 GB|Storage:128 GB|   ·   highlights – Title|text~Title|text

A ready-made sample is in src/main/resources/data/products.csv.
